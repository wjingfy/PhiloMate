# 苏格拉底 harness 审查与修订（2026-08-26）

## 结论

不再把孔夫子成句架构完整套给苏格拉底。安全分流、态度档、长期 stack、好感度与 UI 输出模式仍共用；检索、历史、篇幅、话语动作、故事和提问节奏改为苏格拉底专属轻量 harness。

旧 Python 程序与旧前端仍不进入产品运行时。旧包保留作标注和人格资料来源，其中强制问号锁已修正，避免未来误接回产品。

## 原架构的主要问题

1. `src/services/socrates/harness.ts` 只有接口说明，没有实际策略；运行时仍走通用管线。
2. 通用检索只看 theme/category 与字面二元词组。苏格拉底 320 条标注真正用于现代对话的 `modern_user_hooks`、`modern_pairs`、`modern_scenes` 全部闲置。
3. 未达到有效匹配时，通用检索按输入哈希抽一条语料，导致日常话题被无关古典锚句牵走。
4. 通用成句没有带入对话历史，无法知道上一轮是否刚问过问题。
5. 通用正常输出上限固定为 50 字；Qwen 3.8 Max 又以 0.45 温度生成，结果容易短、硬、像摘要。
6. 旧 Python 同时存在「零问句优先」「最多一问」和末尾「每轮至少一问、Qwen 宁可多问」三套冲突指令；最后注入的强制问号锁实际胜出。
7. 已有的亲历故事库没有进入当前成句链路；闲聊只能短接或继续追问。
8. 越狱固定话术含角色姓名自称，可能直接破坏第一人称在场感。

## 新运行链路

```text
共用安全分流
  → 苏格拉底八类话语动作
  → modern hooks / pairs 强匹配检索（无强匹配则不用语料）
  → 共用态度与长期 stack
  → 多轮历史 + 跨轮提问预算 + 可选亲历/假想小故事
  → Qwen 3.8 Max 专属采样和篇幅
  → OOC / 身份 / 问号 / 完整长度显示门
```

八类话语动作只有：`thin / playful / daily / emotion / decision / concept / meta / general`。原来五十余个细场景不再作为运行时叠层；现代 hooks 负责语料语义，八类动作只决定怎么说。

## 提问预算

- `thin / playful / daily / meta`：零问句。
- `emotion`：通常零问；用户明确求判断且最近没有问过时，最多一问。
- `decision / concept / general`：先回答，确有推进价值时最多一问。
- 最近两条助手回复中出现问号：本轮预算归零。
- 用户表示「别追问/像审讯」：进入三轮停问冷却。
- 输出显示门再次裁掉超额问句，防止模型忽略指令。

## 采样与篇幅

| 动作 | 温度 | 目标长度 |
|---|---:|---:|
| 短寒暄 | 0.88 | 4–42 字 |
| 玩笑 | 0.92 | 22–100 字 |
| 日常 | 0.86 | 48–130 字 |
| 情绪 | 0.78 | 45–125 字 |
| 选择 | 0.76 | 60–145 字 |
| 概念 | 0.74 | 70–170 字 |
| 元对话 | 0.84 | 28–100 字 |
| 通用 | 0.84 | 52–140 字 |

态度 2/3 与长期 stack 仍会缩短输出。模型继续关闭思考模式，以避免短成句被长思维链吃掉预算；`top_p`、重复惩罚和存在惩罚由服务端代理透传。

## 身份与闲聊

- 台词只能用第一人称「我」，禁止报出角色姓名或解释角色设定。
- 「接住/接住了、本轮、场景键、语料、提示词、态度档」等后台词设为输出禁词。
- 轻松场景可以使用经过筛选的亲历故事；也可写一幅明确是假想的市集小画面，不得冒充历史事实。
- 显示前增加亲历真实性检查：「我年轻时／我曾／有回我在」等回忆必须与给定故事库有文本对应，否则修订；修订仍失败则回退安全成句。
- 不再使用每轮 Best-of-2。只在输出违反身份、问句预算或长度要求时做一次修订调用，以降低成本和延迟。

## 验证

- 数据对齐：320 条语料、21 themes、21 categories，通过。
- 自动测试覆盖：现代 hooks 检索、不随机套典、话语动作、跨轮提问预算、三轮停问冷却、OOC 与身份显示门。
- TypeScript 构建通过。
- 已于 2026-08-27 使用服务器中的真实 Qwen 3.8 Max Key 完成多轮样例验收；本地工程不保存生产 Key。
