# 组装决策记录

## 权威顺序

1. `通用(1)/通用/规范/强制对齐清单.md` 与预标注 schema。
2. 各角色数据包、`入口.md` 和口吻材料。
3. 用户组装要求。
4. 为保证可执行而增加的本地兜底，不得改变前述统一算法。

## 架构取舍

- 运行时采用 Vite + 浏览器 TypeScript + Node 模型代理。
- `docs/deliveries/confucius-select-generate.zip` 已与旧孔子包合并：旧入口、评问与原成句材料保留，新包补齐选择、情绪、跨轮、转题和生成依赖。模型可用时接入完整 `runConfuciusPipeline`；无模型或异常时回退统一 harness。
- 新包中态度、stack、类型等公共文件没有覆盖 `通用(1)` 的权威实现；服务端模型适配器按本项目 `/api/chat` 合同改接。
- 王阳明和福柯的 TypeScript 交付保留为原始参考；产品使用统一 harness，避免把角色包中的重复 stack/定档实现接入主链。
- 苏格拉底 Python 程序和原前端不进入运行时；正常对话由 `src/services/socrates/harness.ts` 的专属轻量 harness 负责，使用苏格拉底自己的现代钩子/对话对标注、历史窗口、话语动作和跨轮提问预算。它只与产品共用安全分流、态度档、长期 stack 与输出模式，不套用孔夫子的选典和成句约束。
- 没有模型密钥时使用保守态度比照和角色化本地成句；有密钥时通过 `/api/chat` 由服务端转发，浏览器不接触密钥。
- 所有美工素材只进入视图层，不改变定档/select/generate。当前动作源是大体积 GIF，运行时转为 450×800 动画 WebP，并只把当前角色、当前态度对应文件设置为 `<img src>`。
- 对话页采用单一沉浸式场景画布：背景、人物、消息气泡和输入栏分层叠放；进入对话时隐藏开发调试栏和资料头部，其余功能由场景快捷入口访问，不改变统一 harness。
- 头像脸红状态使用现有亲近档位触发（分数 ≥80）；窗台成长使用同一分数映射为种子、嫩芽和三档品种差分，不另造好感公式。
